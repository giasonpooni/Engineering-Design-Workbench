# Parameterized System Board V1\n\nThe Board is the next NET substrate above typed computational objects and below semantic execution.\n\nIt is a parameterized, typed relational graph. The separately qualified [Visual Editor V1](SYSTEM_BOARD_VISUAL.md) is a projection and candidate-edit surface over this same Board; it is not a second scheduler or state store.\n\n## Core object\n\nA Board contains typed nodes, typed sockets, parameter domains, relational edges, hierarchical groups, scale coordinates, uncertainty semantics, provenance requirements, authority requirements, invariants and validity conditions.\n\nOPERATION nodes name semantic capabilities, never engines. Board compilation lowers those nodes through the existing semantic capability plane into the ordinary NET experiment contract.\n\n## Typed sockets\n\nA socket carries:\n\n- schema;\n- unit;\n- frame;\n- scale metadata;\n- uncertainty semantics;\n- provenance requirement.\n\nDATAFLOW edges require all of those fields to match exactly. A float that represents latitude therefore cannot be connected to a pressure or material modulus socket merely because the underlying bits are numeric.\n\n## Parameters\n\nParameters expose a current value plus a declared domain:\n\n- FIXED;\n- ENUM;\n- RANGE;\n- LOG_RANGE.\n\nV1 validates values against the domain but does not yet execute sweeps, distributions, trajectories or optimizers. Those are the next parameterization layer.\n\n## Groups\n\nHierarchical groups collapse complexity without destroying inspectability. Each node has one direct group in V1, while groups may nest acyclically.\n\n## Compilation\n\nOnly DATAFLOW and DEPENDENCY edges participate in execution compilation. SEMANTIC, SPATIAL, TEMPORAL, AUTHORITY and SCALE edges remain visible relational structure and are retained as non-execution edges.\n\nThis is deliberate: related objects do not automatically imply recomputation.\n\n## Board to Needle\n\nThe first qualification compiles a three-operation oscillator Board through the semantic plane, executes it through the existing Session, then applies Needle to one exposed channel parameter.\n\nThe same graph therefore supports human/agent parameterization, compilation, selective recomputation and delta observation without separate semantics for each interface.\n\n## Next layers\n\nAfter V1 is qualified, priority extensions are:\n\n1. parameter sweeps and distributions;\n2. validity/loss budgets on explicit transformation nodes;\n3. sensitivity and uncertainty operators over Board parameters;\n4. graphical projection of groups/sockets/deltas — first bounded implementation in Visual Editor V1;\n5. connected visual click-to-Needle execution after the isolated edit-spec boundary is qualified;\n6. scale-aware navigation across molecular/continuum/component/facility representations.\n\nThe Board remains descriptive and compilable only: it does not select providers, mutate canonical state, admit state, release artifacts, or authorize physical action.\n
