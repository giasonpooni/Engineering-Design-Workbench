# Parameter Program V1\n\nParameter Program is the first deterministic navigation layer over the System Board parameter space.\n\nIt turns an exposed Board parameter into an explicit family of immutable candidate Boards without executing or accepting any candidate.\n\n## Supported generators\n\n- VALUES: explicit ordered values;\n- LINEAR: inclusive deterministic linear grid;\n- LOG: inclusive deterministic logarithmic grid.\n\nAll candidates must remain inside the parameter domain already declared by the Board.\n\nV1 deliberately excludes stochastic distributions, trajectories, optimization variables and stochastic processes. Those require additional semantics and evidence rather than being smuggled into a generic sweep.\n\n## Flow\n\nbase Board -> parameter program -> immutable candidate Boards -> ordinary Board compilation -> ordinary NET experiment.\n\nThe graph continues to determine dependency consequences. The Parameter Program only varies one exposed coordinate.\n\n## Mathematical interpretation\n\nIf a Board describes a family M(theta), Parameter Program V1 provides a finite deterministic sample of one coordinate of theta. It is therefore a practical first step toward treating the Board as a navigable configuration/model space without claiming a full moduli-space formalism.\n\n## Authority\n\nParameter Program never optimizes, executes providers, accepts a candidate, mutates the base Board, admits state, or authorizes physical action.\n
