# Needle V1\n\nNeedle is a first-class intervention operation over a retained NET computational graph.\n\nIt means:\n\n> select a bounded typed object, alter it immutably, compute the declared dependency closure, rerun only that closure, reuse unaffected retained results, and expose the delta.\n\nFor V1 the addressable object is intentionally narrow: an existing experiment node parameter.\n\nLater versions can generalize the same grammar to graph edges, models, representations, scale coordinates, spectral coordinates and visual selections.\n\n## Formal shape\n\nFor dependency graph GD=(V,ED) and target s in V, V1 computes the target plus every declared descendant reachable through dependency edges.\n\nThe operational chain is:\n\nbaseline graph-run -> immutable parameter replacement -> candidate experiment -> dependency closure -> reuse unaffected nodes / rerun affected nodes -> typed delta projection.\n\nThe dependency closure is intentionally not called causal closure. A declared dependency may be conservative, may only enforce ordering, or may not represent a physical causal edge.\n\n## Immutable history\n\nNeedle never rewrites the baseline graph-run or canonical state. The plan is bound to the baseline graph-run content identity and records the exact target node + parameter, before value, replacement value, and propagation policy.\n\nThe candidate is a new ciw.experiment.v1.\n\n## Selective recomputation\n\nciw.needle-run.v1 records the dependency closure, rerun nodes, reused nodes, exact baseline result identities for reused nodes, fresh executions/results for rerun nodes, and source evidence identity.\n\nUnchanged branches are not executed again.\n\n## Delta projection\n\nciw.needle-delta.v1 is a renderer-friendly projection containing, per node: reused/rerun/unresolved status, baseline/candidate result content identities, whether scientific result data changed, numeric-leaf change counts, maximum absolute numeric delta, and a bounded sample of changed JSON paths.\n\nThis is not yet a visual renderer. GSV, Godot, Blender, and scientific visualizers can consume the typed delta later.\n\n## First qualification workload\n\nThe real built-in oscillator graph contains statistics(q) -> spectrum(q), plus an independent energy_statistics(energy) branch.\n\nNeedle changes statistics.channel from q to v.\n\nThe declared affected closure is {statistics, spectrum}, while energy_statistics is reused from the baseline.\n\nExpected observation:\n\n- statistics reruns and changes;\n- spectrum reruns because it is a declared descendant, but its own q-spectrum output remains unchanged;\n- energy statistics does not rerun.\n\nThis distinction is deliberate: dependency closure and observed output change are not the same thing.\n\n## Scope\n\nNeedle V1 does not yet support arbitrary source-code/binary edits, operation replacement, graph-edge mutation, canonical-state mutation, causal inference, automated acceptance of a candidate, or model/scale/spectral/visual needling.\n\nThose become follow-on experiments after the selective-recomputation invariant is qualified.\n
