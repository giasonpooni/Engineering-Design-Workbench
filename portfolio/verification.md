# Verification surface

The portfolio surface is generated by `scripts/build_instrument_surface.py`.
It produces:

- `instrument.json` — a copy of the canonical instrument manifest;
- `example_input.json` / `example_output.json` — the synthetic canonical specimen;
- `failure.json` — a deliberate reference-frame refusal;
- `figures/overview.svg`, `uncertainty.svg`, `refusal.svg`;
- `instrument-card.json` — generated operational metadata;
- `verification.json` — test/runtime/source/artifact evidence.

CI regenerates this surface from the installed package after the distribution
checks. The report binds software evidence to the source revision and release
artifact hashes when `release-evidence.json` is available.

A passing software verification report does **not** establish physical
synchronization accuracy, calibration traceability, correctness of an externally
supplied clock model, or publication to PyPI.
