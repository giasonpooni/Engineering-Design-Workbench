# Authored projectile experiment

See [the operating guide](../../docs/INTERACTIVE_PROJECTILE.md) for the actual
commands and boundaries. `projectile.json` is a declared scenario, not a recorded
measurement or proof. Blender authors one small GLB; Godot and Bevy run independent
point-projectile implementations; NET retains and compares their observations.

Build the source-checkout Bevy adapter with its Cargo.toml, then preserve the
resolved Cargo.lock alongside the executable and investigation. The native gate
requires all three actual tools and fails instead of substituting a Python demo.
