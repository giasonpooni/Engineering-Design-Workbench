Prediction → transformation → counterexample → proof
Coordinates change by [v]B = P⁻¹[v]A. The same linear map has matrix B = P⁻¹AP. Therefore P B [v]B = A[v]A. The diagram commutes because P P⁻¹ is the identity.
Trace, determinant, rank and the characteristic polynomial survive similarity. Individual matrix entries, coordinate components and the uncorrected Euclidean length of the coordinate tuple generally change. The coordinate metric becomes G = PᵀP, so [v]BᵀG[v]B = vᵀv.
Covariance, loss and application
The exact Python instrument also transports full covariance as ΣB = P⁻¹ΣA(P⁻¹)ᵀ and verifies PΣBPᵀ = ΣA. Missing frames, mismatched units, geometry coarsening, identity aliasing, missing covariance, singular bases and contradictory metadata produce retained refusals.
The sensor experiment uses the same basis contract after affine calibration and Gaussian conditioning. The 1792 recipe checks what a character knows after observation, time progression and save/reload. A coarse representation can preserve a statistic while losing support for a requested intervention; the existing finite preservation suite supplies that counterexample.
A singular operator A is a legitimate transformation with information loss. A singular P cannot serve as a basis change. Which properties must survive depends on the declared task.
