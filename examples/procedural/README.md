# Procedural graphics examples

These requests are generated by the installed example APIs. They demonstrate normalized graphics geometry, procedural RGB textures, and visual appearance. They do not describe acquired measurements or validated physical materials.

| Request | Representation | Useful check |
| --- | --- | --- |
| `gyroid.json` | Implicit gyroid band | Boundary clipping, connected structure, grid sensitivity |
| `sphere.json` | Implicit sphere | Analytic radius, closed topology, area convergence |
| `wave.json` | Implicit wave | Open boundary, vertex residual, winding |
| `parametric.json` | Transformed parametric torus | UV sampling, periodic seams, genus, area/volume refinement |
| `texture.json` | Procedural RGB field | Pixel-center sampling, RGBA8 quantization, PNG reopening, emitted GLSL binding |

Run a mesh example in a new retained directory:

```sh
net graphics run examples/procedural/parametric.json --output-dir torus-run
net graphics inspect torus-run
net graphics verify torus-run
net graphics replay torus-run --output-dir torus-replay
net graphics export torus-run --format obj --output torus.obj
```

Run a texture example:

```sh
net graphics run examples/procedural/texture.json --output-dir texture-run
net graphics inspect texture-run
net graphics verify texture-run
net graphics replay texture-run --output-dir texture-replay
net graphics export texture-run --format png --output texture.png
```

Keep each OBJ or PNG identity sidecar with its export. Use a fresh output path each time: retained history and exports are create-only.

For the notation editor, parameter controls, high contrast, and live WebGL viewport:

```sh
net graphics serve --output-dir graphics-history --port 8788
```

Open `http://127.0.0.1:8788`. A preview is transient; retain a run explicitly to record its request and execution. Generated GLSL is emitted from validated notation. The CPU texture checks do not establish GPU pixel equality or physical material properties. See [the workbench guide](../../docs/PROCEDURAL_GRAPHICS_WORKBENCH.md) for contracts and authority limits.
