# pyramid-method-gap (investigation sample)

Motto alignment: **State / Variation / Invariance**.

This folder is a terminal investigation sample. It does **not** register a
workbench kind, CIW operation, or schema in this pass.

## Sanitized frame

- **Subject:** population-age structure plus a method-continuity gap under
  cheaper generative tools.
- **Claims:** promised transfers and services that must be paid from verified
  throughput, not from speeches or token volume.
- **Live method:** a checkable workflow another crew can run. Fluency is not
  method. Official “adoption” that copies an old SOP onto a new tool is
  transfer-assumed; inventing the new workflow under load is push.
- **Continuity gap:** generation got cheap; transferable method did not arrive
  with the tool; tacit method also leaves with retiring practitioners.
- **Question this sample may ask:** on a declared analog plant, does a quadratic
  certificate still decrease when a gap-weight parameter moves from a renewal
  chart to a sticky-claims / method-leak chart?
- **Question this sample may not ask or answer:** forecasts about nations,
  parties, genders, households, or “who wins the century.” No personality types.
  No social-conflict narrative. `may_authorize` stays false. `claim_scope` is
  computational-integrity-only.

## Declared plant

Continuous affine family

\[
A(\theta) = A_0 + \theta A_1,\quad \theta \in [0,1]
\]

State \(x = (c, m, g)\) is a dimensionless deviation from a declared operating
point \(x = 0\):

| symbol | meaning |
| --- | --- |
| \(c\) | claim load above verified throughput |
| \(m\) | live-method deficit |
| \(g\) | unchecked generation surplus |

**\(A\) is declared, not identified** from census, fertility, GDP, chat logs, or
any evidence corpus. The common quadratic \(P\) is solved from the continuous
Lyapunov equation on \(A_0\) only with \(Q = I\). That common \(P\) is
**conservative**.

Teaching split under that common \(P\) (host numpy):

| \(\theta\) | spectral abscissa \(\alpha(A)\) | \(\max\mathrm{eig}(A^\top P + P A)\) | reading |
| --- | --- | --- | --- |
| 0 | \(-0.150\) | \(-1.000\) | decrease definite |
| 1 | \(+0.361\) | \(+2.402\) | no certificate |

Fail at \(\theta = 1\) means **this \(P\) does not certify this \(A(1)\)**, not
that a country left a basin. \(\theta = 0.5\) already loses Hurwitz on this
\(A\); the runner reports that and does not hide it.

## Godot presentation (optional)

Host-computed presentation only. Generate a local render JSON, then open the
**Analog** tab in the Godot viewport. Meshes are presentation; numeric cards
come from the host JSON and are never reconstructed from displayed geometry.
No websocket protocol and no CIW kind are involved.

```sh
python examples/pyramid-method-gap/run_analog.py \
  --write-render examples/pyramid-method-gap/results/analog_render.json
godot --path godot
```

The Analog tab loads `../examples/pyramid-method-gap/results/analog_render.json`
relative to the Godot project by default, or an explicit path after `--`
(for example `godot --path godot -- examples/pyramid-method-gap/results/analog_render.json`).
If the file is missing the tab shows STALE and freezes interaction.

## Evidence seam

[Evidence-and-State-Management (ESM)](https://github.com/giasonpooni/Evidence-and-State-Management)
is the **only** allowed retention path for a later run receipt from this sample.

ESM holds evidence retention, versioned state, admission, release, and
correction/recall. Local intake stores bytes plus a receipt; inspection
recomputes the receipt. The CIW path for instrument candidate-evidence is
`inspectInstrumentResult` / `captureInstrumentResult`. Capture retains
**UNADMITTED** candidate evidence; `canonicalAdmission` stays false unless a
separate domain admission is run. Demonstration corpora (Caravan / Tradewind /
Landshark fixtures) are not live demographic feeds and must not be treated as
“data to model the pyramid.” Nothing admits on its own behalf: this sample must
not promote its own analog output to world state.

Any JSON written by `run_analog.py` is a **local artifact**, not admitted state.
An optional later capture would use the existing candidate-evidence adapter, not
a new store. No silent join across Caravan / Tradewind / Landshark into
\((c, m, g)\). If any series is ever bound, source-knew-by-\(D\) versus
system-held-at-\(K\) stay distinct.

**ESM checkout on this computer:** not present at sample authoring time. The
`npm run instrument:inspect` CLI shape (bundle path, review context, operator
runtime with python digest and repo revisions) is therefore
**unsupported-until-pinned** here; no pins are invented in this README.
