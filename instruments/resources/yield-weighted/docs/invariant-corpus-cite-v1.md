# Invariant corpus cite

Cite `validation/invariant-corpus-v1.json`.
The corpus pins department names, letters, and refuse codes for v0.
It is not a world certificate.

This historical 0.1.0 vocabulary corpus remains unchanged by the 0.2 reservation
API. It does not certify the new reservation lifecycle, which is exercised by
`tests/test_reservations.py`; see the [migration contract](../README.md#reservation-api-02).
