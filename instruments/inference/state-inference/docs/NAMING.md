# Naming and compatibility

| Surface | Technical name |
| --- | --- |
| Project title | Geometric State Inference Engine |
| Intended GitHub repository slug | `Geometric-State-Inference-Engine` |
| Python distribution | `geometric-state-inference-engine` |
| Python import | `geometric_state_inference` |
| Previous specification title / original repository slug | `State-Inferential-Cortex` |

The project title and package name do not depend on the GitHub slug. If the hosting rename is still pending, use the existing repository URL to clone. Documentation uses relative links internally so it works at either URL. No earlier Python import API existed in the original three-file specification.

A hosting rename must preserve repository identity, history and visibility. It does not rename neighboring packages, schema identifiers, source evidence or historical execution/verification records.
